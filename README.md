# 🛠️ Patchwork

**Patchwork** is a modern platform designed for builders, creators, and experts to build in public (or private) and establish domain credibility. It provides dedicated "Build Rooms" where makers can share live updates, gather observer feedback, and request targeted reviews from verified industry experts.

## ✨ Features

- **🚀 Build Rooms**: Dedicated spaces to log daily progress, share wins, and document your build journey.
- **👀 Observer Hub**: Allow followers and stakeholders to track your progress and react to your updates (Sharp ✦, Pushback ↩, Tell me more ?).
- **🎓 Verified Experts**: A specialized system where builders can request reviews from domain experts. Experts manage their availability, open slots, and track their review scores.
- **🏆 Gamified Reputation**: Earn reputation points based on consistency, engagement, and expert validation.
- **🎨 Premium Interface**: A highly responsive, glassmorphic UI built with React, Tailwind CSS, and Framer Motion for buttery-smooth animations.

## 💻 Tech Stack

- **Framework**: React 18 (via Vite)
- **Routing**: React Router v7
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Data Management**: React Query

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository and navigate into the project directory.
2. Install the dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the local development server:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

### Building for Production

To create a production build:
```bash
npm run build
```
The optimized bundle will be generated in the `dist` folder.
